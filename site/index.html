Search in your terminal.

lobster is a security-hardened terminal media streamer. It searches movies, series and anime, then plays them in mpv, vlc, iina or celluloid, or downloads them with ffmpeg. Every unsafe shell eval from the original script is replaced with structured Go.

Install View on GitHub

What it does

  • Search and trending

    Search by name, or browse trending and recently added content, in an fzf menu.

  • Your player

    Stream in mpv, vlc, iina or celluloid. Pick with --player.

  • Continuous playback

    Auto-plays the next episode after a 10 second countdown, with next, previous, replay and cross-season navigation.

  • Downloads

    Save for offline viewing with ffmpeg using --download.

  • Subtitles and quality

    Automatic subtitle language matching, and 360, 480, 720 or 1080 quality selection with -q.

  • Scriptable

    JSON output and prompt-free find, episodes and play commands for scripts and agents.

  • Hardened

    Structured, auditable Go in place of shell interpolation. Runs on macOS, Linux and Windows.

  • Health checks

    lobster doctor probes each source and names the stage that broke.

Install

Linux and macOS. The script detects your OS and architecture and installs dependencies such as fzf.

curl -sSfL https://raw.githubusercontent.com/billmal071/lobster/main/install.sh | sh

Windows, in PowerShell. Installs mpv, fzf and ffmpeg too.

irm https://raw.githubusercontent.com/billmal071/lobster/main/install.ps1 | iex

From source on macOS or Linux.

brew install go fzf mpv
git clone https://github.com/billmal071/lobster && cd lobster
go build -o lobster .
sudo make install

You need fzf and a player (mpv by default). ffmpeg is required only for --download. Prefer a binary? Grab one from Releases.

Quick start

lobster
Open the interactive search.
lobster doctor
Check which sources work right now, and where the others break.
lobster trending
Browse trending content.
lobster find <query>
Search and print JSON, no prompts. Each result has a ref.
lobster play --ref <ref>
Play the exact title a ref names. Series also need --season and --episode.
--base <source>
Choose the content source for a run.
--download <path>
Download instead of playing.

Sources

Select one with --base or base in config. The default, auto, picks per content type and tries HTTP sources first. Availability varies from week to week: lobster doctor is the live answer.

HTTP streaming

  • flixhq.ws films and series, the general source auto maps to
  • tbcpl, 1shows.org films and series
  • animeonsen anime
  • animeheaven anime, only when you name it

BitTorrent, opt-in

  • yts films
  • eztv series
  • nyaa anime
  • 1337x films and series

These join a torrent swarm and expose your IP address to its peers. They are used only if you set torrent_fallback = true or name one with --base, and under the fallback only after every HTTP source has failed.

lobster is a tool for finding and playing media. You are responsible for using it only with content you have the right to access.
